# Interactive Web Elements

## Project Overview

This project demonstrates the implementation of interactive web elements using HTML, CSS, and JavaScript. It focuses on basic user interactions, DOM manipulation, and dynamic content updates.

## Features

### Dark Mode Toggle

* Switch between light and dark themes.
* Improves user experience and accessibility.

### Dynamic Message Update

* Changes the welcome message when the button is clicked.
* Demonstrates DOM content manipulation.

### Interactive Counter

* Increase and decrease counter value.
* Updates content dynamically without refreshing the page.

### Show/Hide Content

* Toggle visibility of content using JavaScript.
* Demonstrates element manipulation through DOM methods.

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
